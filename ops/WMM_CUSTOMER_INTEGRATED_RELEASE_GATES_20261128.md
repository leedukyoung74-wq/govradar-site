- P0 상담 완료 화면이 단순 GET으로 열려도 고객에게 '신청 받음' 표시: **7개 언어 x 2 유형**에 실제 저장/처리 번호를 확정하는 것은 아니라고 명시. 원본 생성 코드에 같은 문구 반영해야 다음 빌드에서 사라지지 않음.
- P0 M1 20,000원·200,000원 VAT 포함: 공개 홈페이지 7개 언어 통일. 결제 상품표도 같은 금액. 카드 결제는 WMM_PAYMENT_LIVE_ENABLED가 true인 경우에만(키와 별도) 진입하도록 보호. 이 리뷰에서 live flag, secret, Toss API를 절대로 설정하지 않음.
- P1 7개 언어 FAQ /support/와 홈페이지 링크: 브라우저 로컬 검색, WMM 및 GCSME KR/UK 분리, 실제 고객지원 티켓·AI 자동 접수라고 주장하지 않음.
- P1 /es/fr/vi/id pricing 및 request: 영어 폴백 8개는 **다국어 완성**으로 계산하지 않음. 번역 법률검토 필요.
- P0 외부 WMM 홈페이지 wmm-hoa.com VAT 별도 표기와 GCSME.kr 구형 도메인 안내: 별도 사이트 원본/CMS에서 수정; GOV RADAR PR로 수정 불가.
