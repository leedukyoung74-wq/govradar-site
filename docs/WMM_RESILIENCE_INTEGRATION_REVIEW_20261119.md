# WMM GOV RADAR / 재난 대비센터 통합 검수 — 사전 비교서
기준: 2026-11-19 · PR #55 검토 전용 · 운영 배포 금지

## 검토한 소스와 한계
- 기존 `ko/prepare/index.html`: main 브랜치에서 실제 본문 확인. 기존 긴급 대비 안내·20개 생활필수품 분류·성인 2명 14일 비축량·상품 예시·기존 회원/로그인 UI를 제공한다. 실제 운영 브라우저 렌더링은 확인하지 못했다.
- 기존 `ko/ready/`: 인수인계 및 기존 페이지 내 링크로 확인했지만, 이번 main 브랜치의 `ko/` 파일 목록에서 해당 디렉터리가 확인되지 않는다. 실제 라이브 페이지 내용은 아직 검증되지 않았다. 무단 생성·덮어쓰기 금지.
- 신규 `/{ko,en,es,fr,ar,vi,id}/resilience/`: PR #55 전용 페이지. 가구별 식수·식량·전력 산식, 국가별 식품 예시·미검증 상태, 16항목 로컬 체크리스트, 자립 전원 개념도. 기존 `prepare`의 상품 리스트를 다시 복제하지 않는다.

## 현재 배포 판단
아직 스테이징 사이트를 생성하거나 운영 도메인에 배포하지 않았다. 운영 URL을 외부 도구에서 가져오지 못해 라이브 HTML/스크린샷 직접 비교 미완료. PR #54·#55를 병합하지 않았다. `main`, 기존 수집기/SQLite/Windows 예약 작업은 변경하지 않았다.
