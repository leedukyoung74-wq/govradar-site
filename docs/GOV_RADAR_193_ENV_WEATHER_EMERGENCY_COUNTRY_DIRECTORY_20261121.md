## 검증과 운영상 주의

1. 환경 관련 기관 사이트는 장기 정책·환경오염·기후자료를 제공할 수 있지만, 실시간 재난 경보망이 아닙니다.
2. 날씨 기관은 예보/경보의 가장 적절한 공식 원천이나, **API 제공·무료 데이터 재배포 권한을 의미하지 않습니다**.
3. 재난/비상사태 기관의 홈페이지 링크는 긴급 신고 기능이 아닙니다. 현지 긴급전화·정부 지침을 우선합니다.
4. 193개국에는 세 항목 모두 화면이 나오며, 실제 국가기관을 확인하지 못한 분야는 국제기구 디렉터리 링크와 함께 **미연결**로 표시합니다. 국제기구 공통 디렉터리는 579개의 국가별 공식기관 연결 완료 수에 포함하지 않습니다.
5. 본 카탈로그는 `main/src/live/data` 운영 홈페이지에 아직 배포되지 않았습니다.
