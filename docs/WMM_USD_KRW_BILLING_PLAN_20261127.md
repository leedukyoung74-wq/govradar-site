## 1. 공개 소스 확인 (현재 요금)
- 한국어 원문 `ko/pricing/index.html`: 분석 회원 월 **KRW 19,800** (VAT 포함) / 연 **KRW 198,000**, 자동 갱신 없음. 적합도 검토 KRW 100,000 (VAT 별도); 국가 진출 브리프 KRW 300,000부터 (VAT 별도); 기관 라이선스 연 300만/600만/990만 원 (VAT 별도).
- 영어·스페인어·프랑스어·아랍어·베트남어·인도네시아어 가격표도 KRW 가격으로 기재됨.
- 공개 주문 절차: 신청→견적서→계좌이체, **카드 결제 아직 열리지 않음**. 실제 가입자 유료 자동 결제·구독 갱신을 구현했다는 증거 없음.

## 2. WMM 권장: 국가별 독립 가격표, 하나의 결제 기록
- 해외 국제 상품: **USD 가격을 기본 표시/청구 통화**로 제안.
- 한국 소비자/사업자: 국내 상거래 및 세금계산서용으로 **KRW 가격 유지**.
- 나라/통화가 자동 추정돼 잘못 청구되지 않도록 결제 전 사용자 선택 + 최종 확정 가격/통화/세금/갱신 조건 표시.
- **판매국가별 고정 판매가격**을 사용하고 페이지 조회 시점 환율로 청구액을 바꾸지 않음. 환율은 회계/BI 집계용만.
- 기존 국내 가격과 달리 해외 제안가: 분석 월 **US$19**, 연 **US$190** (*마진 검토용 제안, 아직 확정/게시 아님*). 국내 KRW 가격과 실제 환율 환산 동등성을 보장하지 않음. 이중 가격은 지역별 가격 정책으로 명확히 고지.
- 인건비와 맞춤 보고서 비용이 수반되는 다른 상품은 USD 임의 환산 없이 **맞춤 견적**만 제공. 확정 가격과 실제 제공 범위를 대표가 승인해야 함.

## 4. 결제 기능 활성화 전 조건
1. 상품/가격/국가/고객유형/세액 및 환불 약관 검수: 한국 B2C 총액 표시, 해외 국가별 과세/소비자법.
2. 실제 PG 계약·MID·수수료·정산 통화·환불/차지백·사업자 심사 확인.
3. 가격을 정수 최소화폐단위 KRW(원) / USD(센트)로 저장; 프론트엔드 계산만 믿지 않음.
4. 주문 생성 시 통화·할인·세금·총액·일시 동결 후 **서버에서 금액 검증**.
5. 웹훅 서명 검증, 중복/재시도 멱등성, 성공·실패·환불·분쟁 상태 검사.
6. 고객별 멤버십 부여는 결제사 서버 검증 이후만. 문의 제출/Netlify Forms 기록은 결제 성공이 아님.
7. 만료/환불/신용카드 정보 직접 저장하지 말 것; 결제 데이터와 문의 데이터를 BI에서 구분.
8. 실제 결제/구독 자동갱신은 기본 **비활성**. 사용자가 명시적으로 동의하고 준비될 때까지 유지.

## 5. WMM BUSINESS MANAGER 분석 기준
- 원거래 금액과 원통화(USD/KRW) **절대 덮어쓰지 않기**.
- 현재 환율과 거래 당시 환율을 별도로 저장하고, 실수령 정산금·PG 수수료·세금·환불을 구분.
- USD와 KRW 금액을 무단 합산하지 않음. 통합 KPI는 지정한 '기준 통화'와 환산시점·출처로 표시.
- 신규 회원 가입≠유료 결제≠실제 수익. 회원수/접수건수/결제완료/환불은 서로 다른 지표.
