# 상품별 표준 양식과 납품 전 검수표

공통 규칙은 [README.md](README.md). 각 상품의 검수표는 그대로 ChatGPT 교차검수 항목으로 씁니다(항목마다 PASS / FAIL / UNKNOWN + 근거 링크).

---

## A. 입찰 적합도 검토 — 공고 1건, 100,000원(VAT 별도), 영업일 3일

**목적:** 이 공고에 들어갈지 말지를 고객이 하루 안에 결정할 수 있게 한다.
**받는 것:** 공고 링크(또는 번호), 고객 업종·실적 요약, 보유 인증, 희망 역할(주계약/하도급/컨소시엄).
**양식:** [templates/fit-review.md](templates/fit-review.md)

섹션 순서:
1. 결론 — 담당자 판단: 참여 권장 / 조건부 권장 / 비권장, 이유 3가지 이내
2. 공고 요약 — 발주처, 재원(세계은행·EU 등), 공고 번호, 계약 형태, 추정 금액, 마감(현지 시각·시간대)
3. 참여 자격 대조표 — 공고 원문 조항 번호 | 요구 내용 | 고객 충족 여부(충족/미충족/확인 필요) | 근거
4. 필요 서류 목록 — 서류 | 발급처 | 예상 소요일 | 번역·공증 필요 여부
5. 현지 파트너 필요 여부 — 필요/불필요/유리, 이유(현지 등록·언어·실적 요건)
6. 일정 — 오늘부터 마감까지 거꾸로 짠 준비 일정(질의 마감, 현장설명회 포함)
7. 위험 — 제재 명단 확인 결과, 환율, 분쟁·재난 상황, 대금 지급 조건
8. 다음 행동 — 고객이 할 일 3가지 이내와 기한
9. 출처 — 공고 원문(T1) 필수

**검수표 (전부 PASS여야 발송)**
- [ ] A1 공고 원문 링크가 열리고, 번호·제목·마감이 원문과 같다(마감 연장 여부 당일 재확인)
- [ ] A2 자격 대조표의 모든 행이 원문 조항 번호를 가진다
- [ ] A3 "충족" 판정마다 고객 자료의 근거가 있다(없으면 "확인 필요")
- [ ] A4 결론이 담당자 이름으로 서명되어 있다
- [ ] A5 마감에 시간대가 있고, 준비 일정이 마감보다 앞선다
- [ ] A6 발주처·주요 상대방을 4개 제재 명단(UN·OFAC·EU·UK)에서 확인했고 결과를 적었다
- [ ] A7 공통 규칙 3·4절 충족(표기, 면책, 금지 내용 없음)

## B. 국가 진출 브리프 — 1개국, 300,000원부터(VAT 별도), 보통 영업일 5~10일

**목적:** 한 나라에서 "어디로, 무엇부터" 들어갈지 정한다.
**받는 것:** 나라, 고객 업종·제품, 목표(수출/정부조달/투자/파트너), 예산·기간.
**양식:** [templates/country-brief.md](templates/country-brief.md)

섹션 순서:
1. 결론 — 권장 진입 경로 1개와 이유(담당자 판단), 첫 90일 할 일
2. 나라 한눈에 — 인구·GDP·성장률·물가·환율(세계은행·환율 피드, 기준 연도·날짜 표기)
3. 정부 우선 과제와 예산 — 고객 업종과 관련된 것만, 금액은 한도/집행액 구분
4. 지금 열린 입찰·공고 전 사업·진행 중 세계은행 사업 — 고객 업종 관련, 마감·금액·원문 링크
5. 최근 낙찰 — 누가 얼마에 이겼나(현지/외국 기업 비율, 한국 기업 실적)
6. 쓸 수 있는 한국 지원제도 — 기관, 사업명, 신청 시기, 링크(T1)
7. 위험 — 정세·분쟁·재난(공식 경보), 제재 명단 현황(국가 제재 아님을 명시), 대금·환율
8. 진입 경로 비교 — 2~3개 경로 | 필요한 것 | 기간 | 비용 범위 | 위험
9. 다음 행동 — 담당자·고객이 할 일, 기한
10. 출처

**검수표**
- [ ] B1 모든 숫자에 출처 링크와 기준일이 있다
- [ ] B2 지표·환율은 GOV RADAR 피드(세계은행·환율)와 같은 값이거나 차이 이유를 적었다
- [ ] B3 입찰 목록의 마감이 모두 오늘 이후이고, 링크가 원문으로 열린다
- [ ] B4 정부 과제는 T1 출처(정부·국제기구 문서)가 1개 이상 있다
- [ ] B5 제재 항목에 "나라 전체 제재가 아님" 문구가 있다
- [ ] B6 진입 경로 추천이 담당자 이름으로 서명되어 있다
- [ ] B7 고객 업종과 무관한 항목이 섞이지 않았다
- [ ] B8 공통 규칙 3·4절 충족

## C. 회원 빠른 검토 — 분석 회원 월 2건 포함

**목적:** 회원의 짧은 질문(이 공고 볼 만한가, 이 나라 지금 어떤가)에 영업일 2일 안에 답한다.
**양식:** 이메일 본문 1장 — 결론 2문장, 근거 3줄(각각 링크), 더 깊게 보려면(적합도 검토·브리프 안내).
**검수표**
- [ ] C1 근거 3줄 모두 링크가 열린다
- [ ] C2 상세 판정(자격 대조표·서류 목록)은 넣지 않았다 — 그건 상품 A
- [ ] C3 "AI 작성 + 사람 검수"와 검수자 이름

## D. 관심 나라 주간 요약·마감 임박 알림 — 분석 회원 10개국

**목적:** 회원이 고른 나라의 이번 주 변화를 5분 안에 읽게 한다.
**양식:** 나라별 3줄 이내 — 새 공고(건수·대표 1건), 마감 임박(D-7 이내), 주요 변화(정부·위험). 숫자는 피드 값만.
**검수표**
- [ ] D1 모든 공고가 발송일 기준 열려 있다(마감 지난 것 없음)
- [ ] D2 숫자가 같은 날 `feeds/today.json`·`feeds/cty/{ISO}.json`과 같다
- [ ] D3 담당자가 읽고 발송 승인했다(사이트 약속: 담당자 검수 후 발송)
- [ ] D4 수신 거부 방법이 있다

## E. 기관 분기 브리프 — 기관 라이선스

**목적:** 지자체·테크노파크·공공기관이 회원사에게 다시 설명할 수 있는 분기 자료.
**양식:** B의 섹션을 기관이 고른 나라·업종 묶음으로. 표지에 기관명·분기, 마지막 장에 회원사 안내용 요약 1쪽.
**검수표:** B1~B8 + E1 기관이 그대로 배포해도 되는 형태(고객사명·내부 메모 없음) + E2 사진·도식 출처 표기

## F. 프로젝트 파트너십 — 첫 상담 무료, 비용은 상담 뒤 결정

**목적:** 실제 사업을 함께 만든다. 산출물은 단계마다 다르다.
| 단계 | 산출물 | 검수 핵심 |
|---|---|---|
| 첫 상담(30분) | 상담 기록 1장: 목표, 대상 나라·사업, 고객이 가진 것, 다음 단계 | 약속한 다음 단계에 기한이 있다 |
| 제안 | 범위·기간·착수금·성공보수·수수료 공개 조항이 있는 제안서 | 반부패·수수료 공개 조항 포함, 대표 승인 |
| 실행 | 파트너 후보 목록, 공급자 등록, 서류, 컨소시엄 구성안, 제안서 | 파트너 실재 확인(공식 등록·웹사이트), 제재 명단 확인 |
| 보고 | 월 1회 진행 보고 | 숫자·결과는 증빙 링크 |

**검수표**
- [ ] F1 파트너·상대방 전원을 4개 제재 명단에서 확인했다
- [ ] F2 성과·실적 표현에 증빙이 있다(없는 실적·후기 금지)
- [ ] F3 비용·수수료가 문서에 모두 적혀 있다

## 자동 사전검사
