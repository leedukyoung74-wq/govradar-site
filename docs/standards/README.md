# GOV RADAR 솔루션 표준 — 공통 규칙

GOV RADAR가 고객에게 보내는 모든 결과물(적합도 검토, 진출 브리프, 회원 빠른 검토, 주간 요약·알림, 기관 분기 브리프, 파트너십 산출물)에 똑같이 적용합니다. 상품별 양식과 검수표는 [products.md](products.md)에 있습니다.

이 규칙은 사이트에 공개한 [검증 원칙](https://radar.wmm-hoa.com/ko/verify/)과 [요금·주문 조건](https://radar.wmm-hoa.com/ko/pricing/)을 결과물 단위로 옮긴 것입니다. 사이트 약속과 이 문서가 다르면 사이트 약속이 우선이며, 이 문서를 고칩니다.

## 1. 누가 무엇을 하나

| 역할 | 하는 일 |
|---|---|
| 수집기 (AI 없음) | 공고·지표·환율·제재·경보를 매일 모으고 품질검사를 통과한 것만 게시 |
| Claude | 초안 작성, 원문 대조, 자동 사전검사(`tools/qa_deliverable.py`) 실행 |
| ChatGPT | 교차검수: 검수표 항목별 PASS / FAIL / UNKNOWN과 근거 링크 |
| 담당자(사람) | 최종 판단(참여 권장 여부 등), 서명, 발송 |
| 대표 | 가격·범위 예외, 환불, 병합·배포·결제 승인 |

AI는 판단하지 않습니다. "참여 권장/비권장", "진입 경로 추천"은 담당자가 정하고 이름을 남깁니다.

## 2. 출처와 판정 (모든 문장·숫자)

- 출처 등급: **T1** 정부·국제기구 공식 문서와 공고 원문 / **T2** 통신사·주요 언론·연구기관 / **T3** 그 밖의 매체·위키·블로그·SNS.
- 판정 표시는 사이트와 같은 7가지만 씁니다: 확인됨, 공식 발표, 일부 사실, 당사자 주장, 단일 출처, 사실 아님, 근거 없음.
- **숫자 하나에 출처 링크 하나.** 링크가 없는 숫자는 쓰지 않습니다.
- 입찰 공고의 자격·서류·마감은 **공고 원문(T1)과만** 대조합니다. 요약 사이트·뉴스는 근거가 될 수 없습니다.
- 금액은 통화와 기준을 함께 적습니다(예: "약정액 US$1.5bn, 세계은행 기준"). 추정 환산은 "≈"와 환율 날짜를 붙입니다.
- 날짜는 `YYYY-MM-DD`, 마감은 현지 시각과 시간대를 함께 적습니다(예: `2026-11-23 09:00 (UTC+02:00)`).
- 확인되지 않은 내용은 결과물에 싣지 않습니다. 꼭 필요하면 "확인 못 함"과 이유를 적습니다.

## 3. 결과물에 반드시 들어가는 것

1. 맨 위 정보: 상품명, 고객사, 대상(나라·공고 번호), 작성일, 자료 기준일, 담당자 이름, 버전.
2. 한 줄 결론(첫 문단). 판단이 필요한 상품은 담당자의 판단과 그 이유 3가지 이내.
3. 본문(상품별 양식의 섹션 순서 그대로).
4. 출처 목록: 번호, 제목, 기관, 날짜, 링크, 등급(T1/T2/T3).
5. 표기: **"AI 작성 + 사람 검수"**와 검수자 이름·날짜.
6. 면책: "공개 자료 기준이며, 계약·투자 전에는 원문을 확인하세요."

## 4. 넣으면 안 되는 것

- 대표 개인 휴대폰 번호, 사업장 주소(연락처는 leedukyoung74@gmail.com 하나).
- 고객이 보낸 자료를 다른 고객 결과물에 쓰는 것.
- 만들어 낸 후기·실적·수치, 근거 없는 예측, "예언" 같은 표현, 종교 용어.
- 제재 명단 숫자를 "이 나라가 제재 대상"으로 쓰는 것(명단 등재 건수일 뿐임).
- 수수료·성공보수를 숨기는 표현(정부·국제기구 사업은 반부패·수수료 공개 조항 적용).

## 5. 납기와 상태

- 입금 확인 후 영업일 2일 안에 착수(사이트 약속). 상품별 납기는 products.md.
- 검수 결과는 PASS / FAIL / UNKNOWN 세 가지만 씁니다. FAIL이 하나라도 있으면 보내지 않습니다. UNKNOWN은 이유를 결과물에 적거나 담당자가 확인해 PASS로 바꿉니다.
- 납기를 못 지킬 것 같으면 납기 전날까지 고객에게 새 날짜와 이유를 알립니다.

## 6. 정정과 기록

- 보낸 뒤 틀린 것이 발견되면 영업일 1일 안에 정정본을 보내고, 버전과 "무엇이 바뀌었는지"를 맨 위에 적습니다.
