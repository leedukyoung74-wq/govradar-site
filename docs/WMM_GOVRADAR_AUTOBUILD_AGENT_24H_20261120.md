# GOV RADAR - 24시간 실제 코딩 에이전트 작업 범위 (승인 전 초안)

상태: AI 에이전트 미가동. 이 파일은 Codex에게 실제 GOV RADAR 코드를 수정하게 할 작업 명세이며, ChatGPT 대화창의 연속 실행을 의미하지 않는다.

## 해외 바이어 공개 시연판 우선
영어 페이지에서 확인 가능한 사업기회, 출처, 마감 상태와 적합성 상담 동선을 먼저 개선한다. 데이터가 빈 경우에는 빈 상태를 명시하고 실제 공고처럼 꾸미지 않는다.

| 시간 범위 | 구현 우선순위 |
|---|---|
| 0~3 | 영어 MDB/사업기회 화면의 빈 상태, 출처·마감일 설명 개선 |
| 4~7 | 해외 바이어용 문의/요청 동선·정보의 검증 가능성 |
| 8~11 | 7언어 공고 출처·접근성·안전 문구 |
| 12~15 | 국가 페이지, 특별지역 분리, 검색·필터 일관성 |
| 16~19 | 스테이징/모바일/키보드/빈 데이터 UI·회귀 테스트 |
| 20~23 | 해외 바이어 시연 준비, 버그 수정, 품질 증거 보강 |

## 매 실행의 실제 작업
1. GOV RADAR의 고객가치가 높은 버그 또는 기능 하나를 선정해 실제 코드와 테스트를 수정한다.
2. 허용 경로: build.py, pages3.py, web/, src/review_pages/, tests/, docs/, schemas/. 최대 8파일·250KB 패치.
3. 가능한 한 오프라인 테스트를 작성한다. 공식 원문을 대조하지 못했으면 공개 접수 상태가 확인됐다고 쓰지 않는다.
4. 기존 URL, 193개국/23개 특별지역 인덱스, 인증·결제·로고·SEO를 훼손하지 않는다.
5. 고객 개인정보·API 비밀·계약 원본을 읽거나 외부에 보내지 않는다.
6. 변경사항, 테스트, 미검증 사항을 명확히 보고한다.

## 승인 전 필수 구성
- GitHub schedule은 기본 브랜치에 워크플로가 있어야 작동한다. 지금은 검토 브랜치 준비만 한다.
- Github 변수: WMM_AUTOBUILD_ENABLED=true, WMM_AUTOBUILD_COST_APPROVED=true, WMM_AUTOBUILD_START_UTC=승인 시각의 UTC ISO8601. 현재는 설정하지 않는다.
- Codex Action은 별도 OpenAI API 인증/사용량 한도가 필요하다. ChatGPT 구독료가 API 요금을 포함하지 않을 수 있다.
- API 프로젝트 예산 상한·알림 설정 및 첫 1회 실행의 비용과 산출물 점검 후 24시간 실행을 승인한다.
- AI 작업 잡은 GitHub 읽기 권한만 가지며, 제안한 패치는 다른 잡에서 검사한 뒤 검토 전용 브랜치에만 커밋한다.
- 운영 main/live, Cloudflare, DNS, 고객 메시지, 결제·자동충전 변경 절대 금지.

- 준비: 자동개발 작업 범위 문서, 안전장치와 CI 테스트 작성.
- 미완료: 인증·예산 승인, 기본 브랜치 워크플로 배치, 24시간 누적 코딩 실행, 운영 배포 및 해외 바이어 서비스 검증.
