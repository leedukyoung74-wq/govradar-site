# GOV RADAR · 자치·특별 지역 및 193개국 국방 공식 출처 — 2026-11-21

## 분류
- 주권국가: `src/countries_meta.json` 기준 193개국. 정부사업·언론·재난과 독립된 `src/country_defence_official_sources.json`에 국방/군 관련 3개 공식 원문 목표를 둔다.
- 자치·특별 지역: `src/regions.json` 기존 23개, `src/territory_official_sources.json`에서 국가와 독립 집계. 지역 정부/경제 3, 서로 다른 뉴스 발행사 3, 환경·기상·비상대응·군사/안보·보건·기반시설 별도 카테고리.
- 국방/군 관련 원문은 국방부, 육·해·공군, 해안경비 등 군사/국방 권한이 실제 확인된 공공기관만. 지역 자체 군대가 없는 경우 `parent_authority` 표기. 입법/경찰기관을 군대라고 분류하지 않는다.
- 공통: HTTPS URL 및 검토 근거 보관, 접근·저작권·RSS/API 권한은 별도 검증. 현재 `not_live_tested`이며 실시간 군사정보·부대위치·작전현황 추적이 아님.

## 검증 및 배포 게이트
1. 기존 지역 23개를 유지하고 주권국가 193개 통계에 지역을 섞지 않기.
2. 193개국 각각 권한상 구별되는 공식 국방기관/군종 링크 최대한 3곳; 군대 미보유 국가일 경우 `no_standing_army` 등 별도 상황 기록(현재는 미확인).
3. 자동화는 공개 공식 자료·이용약관 승인 범위로 제한. 정치·법적 지위가 다투어지는 지역은 주장과 공식 소속을 각각 표시.
4. 링크 HTTP 접근, 기관 현행성, 공식 소유, 중복, 콘텐츠 재이용권한, robots, 현지 접근·제재 확인.
5. 이번 변경은 별도 review 브랜치 데이터와 QA/설계 문서만. `main`, `src/live/data`, 운영 사이트, 고객정보, 결제, 유료 API를 변경하지 않음.
6. 지역별 웹 페이지 카드 및 193개국 국방 원문 표시 UI, CI 통과, 대규모 공식 URL 전수검증, 실제 운영 배포는 **미완료**.
